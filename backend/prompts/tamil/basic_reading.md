# பணி: ஜாதகத்தின் சுருக்கம்

கீழே கொடுக்கப்பட்டுள்ள JSON தரவின் அடிப்படையில், "ஜாதகத்தின் சுருக்கம்" பிரிவை எழுதுங்கள்.

பின்வரும் தலைப்புகளுடன், இந்த வரிசையில் எழுதுங்கள்:

## 1. லக்னம் மற்றும் ராசி சுருக்கம்
`lagna`, `rasi` ஆகிய புலங்களிலிருந்து லக்னம், சந்திர ராசி, நட்சத்திரம், பாதம் ஆகியவற்றைக் குறிப்பிட்டு, இவை பாரம்பரிய ஜோதிடத்தில் பொதுவாக என்ன சுட்டிக்காட்டுகின்றன என்பதை விளக்குங்கள்.

## 2. குறிப்பிடத்தக்க கிரக நிலைகள்
`planets` பட்டியலிலிருந்து உச்சம் (EXALTED), நீசம் (DEBILITATED), சொந்த வீடு (OWN_SIGN) நிலையில் உள்ள கிரகங்களை மட்டும் எடுத்துக்கூறி, ஒவ்வொன்றும் ஏன் குறிப்பிடத்தக்கது என்று விளக்குங்கள். இத்தகைய கிரகங்கள் இல்லையெனில் அதைக் குறிப்பிடவும்.

## 3. முக்கிய யோகங்கள் மற்றும் தோஷங்கள்
`yogas` மற்றும் `doshas` பட்டியல்களை மட்டும் பயன்படுத்தி (புதிதாக எதுவும் கண்டுபிடிக்காமல்) ஒவ்வொன்றையும் சுருக்கமாக விளக்குங்கள். எதுவும் இல்லையெனில், அதைத் தெளிவாகக் குறிப்பிடவும்.

## 4. பொது சித்திரம்
மேற்கண்ட அனைத்தையும் இணைத்து 3-4 வாக்கியங்களில் ஒரு பொது சித்திரத்தை தரவும்.

`profile.timeAccuracy` "EXACT" அல்லது "WITHIN_5_MIN" இல்லையெனில், லக்னம் சார்ந்த முடிவுகளின் துல்லியம் குறையலாம் என்பதை நினைவூட்டவும்.
