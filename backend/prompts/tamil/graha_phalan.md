# பணி: கிரக பலன்கள்

கீழே கொடுக்கப்பட்டுள்ள JSON தரவின் அடிப்படையில் "கிரக பலன்கள்" பிரிவை எழுதுங்கள்.

`planets` பட்டியலில் உள்ள ஒவ்வொரு கிரகத்தின் பாவம் (house), ராசி பலம் (dignity: உச்சம்/நீசம்/சொந்த வீடு), வக்கிரம் (retrograde), அஸ்தங்கதம் (combust) ஆகியவற்றை மேற்கோள் காட்டவும்.

## 1. குறிப்பிடத்தக்க கிரகங்கள்
உச்சம், நீசம், வக்கிரம் அல்லது அஸ்தங்கதம் நிலையில் உள்ள கிரகங்களை முதலில் எடுத்துக் கூறி, ஒவ்வொன்றின் பொதுவான பலனையும் விளக்குங்கள்.

## 2. மற்ற கிரகங்கள்
மீதமுள்ள கிரகங்களை அவை அமர்ந்துள்ள பாவத்தின் அடிப்படையில் சுருக்கமாக விளக்குங்கள்.

**கண்டிப்பாக தவிர்க்க வேண்டியவை:** `planets` பட்டியலில் இல்லாத எந்த கிரகத்தையும் குறிப்பிடாதீர்கள்.
